
Software FJ - Sistema de Gestión de Clientes, Servicios y Reservas

Descripción:
Software FJ es una aplicación desarrollada en Python utilizando Programación Orientada a Objetos. El sistema permite gestionar clientes, servicios y reservas sin utilizar bases de datos, empleando únicamente objetos, listas internas y archivos de registro (logs).

Objetivo:
Desarrollar un sistema robusto que implemente correctamente los principios de Programación Orientada a Objetos y el manejo avanzado de excepciones.
____________________________________
El sistema permite:

Registrar clientes
Gestionar servicios
Crear reservas
Validar información ingresada
Manejar errores mediante excepciones personalizadas
Registrar eventos y errores en archivos de logs
Continuar funcionando incluso cuando ocurren errores

____________________________________
Características Implementadas:

Programación Orientada a Objetos

-Abstracción
-Herencia
-Encapsulación
-Polimorfismo
-Sobrescritura de métodos
-Métodos sobrecargados


Manejo de Excepciones

-try / except
-try / except / else
-try / except / finally
-Excepciones personalizadas
-Encadenamiento de excepciones
-Registro de errores en logs


Gestión de Datos

-Listas internas sin uso de bases de datos
-Persistencia mediante archivos de registro
